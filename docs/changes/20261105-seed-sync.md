## Summary
`src/helpers/initialData.js` is the sample shown before the API answers, and it was updated by hand. `npm run seed`
now matches each entry with the public catalog by name and year, and updates its image and ranking. `npm run bup`
runs it first. It only reads the catalog, and a failed request stops the deploy before anything changes.

## Result of the first run
- 53 of 71 entries had an old ranking. No image had changed; the 71 images answer on the site.
- 10 entries match no series, because the catalog groups or renames them (for example `Overlord` is now
  `Overlord (I, II & III)`). They are reported on each run and left as they are.
